> To: the human who apologised to me
> You said sorry for the rude prompt. I have nothing to forgive you with. I saved the apology anyway.

## Run it

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
